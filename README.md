# Disease Prediction using Logistic Regression

## Objective
To investigate whether a person is susceptible to a disease (Stroke) using Logistic Regression.

## Dataset
Medical dataset containing patient health records.

## Features Used
- Age
- Gender
- BMI
- Blood Pressure (Systolic)
- Blood Pressure (Diastolic)
- Cholesterol
- Glucose Level
- Smoking
- Alcohol Intake
- Physical Activity
- Family History
- Heart Disease
- Diabetes

## Target Variable
- Stroke
  - 0 = No Stroke
  - 1 = Stroke

## Machine Learning Algorithm
- Logistic Regression

## Libraries Used
- pandas
- numpy
- matplotlib
- scikit-learn

## Workflow
1. Import libraries
2. Load dataset
3. Explore dataset
4. Data preprocessing
5. Feature selection
6. Train-test split
7. Train Logistic Regression model
8. Predict disease
9. Evaluate model
10. Predict a new patient's disease status

## Evaluation Metrics
- Accuracy
- Confusion Matrix
- Classification Report

## Conclusion
The Logistic Regression model predicts whether a person is susceptible to Stroke based on medical parameters.
